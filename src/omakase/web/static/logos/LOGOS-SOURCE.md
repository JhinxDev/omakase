# Brand Logos Provenance

All logos in this directory are local vector SVGs bundled with Omakase so the web interface makes zero third-party CDN requests at runtime.

- `openai.svg`: OpenAI emblem from `@lobehub/icons-static-svg` (white mark paired with `#10A37F` OpenAI emerald badge)
- `anthropic.svg`: Claude color starburst (`#D97757`) from `@lobehub/icons-static-svg` (`claude-color.svg`)
- `gemini.svg`: Google Gemini multi-stop gradient star from `@lobehub/icons-static-svg` (`gemini-color.svg`)
- `deepseek.svg`: DeepSeek whale mark (`#4D6BFE`) from `@lobehub/icons-static-svg` (`deepseek-color.svg`)
- `openrouter.svg`: OpenRouter mark (`#818CF8`) from `@lobehub/icons-static-svg` (`openrouter.svg`)
- `openwebui.svg`: OpenWebUI mark (`#F5EFE6`) from `@lobehub/icons-static-svg` (`openwebui.svg`)
- `anilist.svg`: AniList mark (`#02A9FF`) from Simple Icons
- `myanimelist.svg`: MyAnimeList mark (`#4F7DF3`) from Simple Icons
